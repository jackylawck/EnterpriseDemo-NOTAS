📌 專案摘要與治理定位 📌 Executive Summary & Governance Positioning

本儲存庫為一項企業管治開源示範專案，展示如何運用 Microsoft 365 原生低代碼生態與「治理即代碼」（Governance-as-Code）理念，構建零額外授權的考勤與防虛報內控系統。

This repository is an Enterprise Demo demonstrating how to implement Governance-as-Code using native Microsoft 365 standard connectors to build a zero-license attendance and anti-fraud internal control engine.

EnterpriseDemo-NOTAS 將傳統易遺失、難以追溯的紙本「非營運時段上班記錄表 (Demo-Form)」全面數位化。系統整合 Microsoft Forms 身分鎖定、Entra ID (`Get user profile V2`) 目錄防呆攔截、三級動態電子簽核（部門主管 ➔ 人力資源部 ➔ 高階營運主管）、HKT (UTC+8) 標準時區校正以及 SharePoint JSON 視覺化審計帳本，全面對齊 ISO/IEC 27001、27701、9001 及 ISO 45001 國際管理體系。

EnterpriseDemo-NOTAS digitizes traditional paper-based "Non-Operating Time Attendance Records (Demo-Form)". It orchestrates Microsoft Forms identity binding, Entra ID (Get user profile V2) directory validation, 3-tier dynamic Approvals (Line Manager ➔ HR ➔ Executive/COD), HKT (UTC+8) timezone normalization, and a SharePoint JSON-formatted audit ledger aligned with ISO/IEC 27001, 27701, 9001, and ISO 45001.

本系統架構 100% 採用確定性條件式規則引擎（Deterministic Conditional Logic），不含任何機器學習或自動化人事評分演算法，明確排除於《歐盟人工智能法案》（EU AI Act）及 ISO/IEC 42001 強制範圍之外；同時所有資料留存於企業本地租戶環境，不涉及跨境數據傳輸。

Operating entirely on deterministic conditional logic without machine learning or algorithmic profiling, this architecture is explicitly scoped out of the EU AI Act and ISO/IEC 42001, while keeping all audit records within the corporate local tenant with zero cross-border data export.

⚙️ 技術工程亮點與開源治理資產 ⚙️ Technical Engineering Highlights & Governance Artifacts

1. 零額外授權架構Zero-License Architecture

全流程僅調用 M365 商業標準版內建標準連接器（Forms、SharePoint、Users、Outlook、Approvals），零 Premium 授權支出。Uses solely M365 Standard Connectors (Forms, SharePoint, Users, Outlook, Approvals) with zero Premium licensing fees.

2. 目錄級異常攔截Scope Exception Handling

配置 Configure run after 監聽 Get user profile (V2) 失敗與逾時狀態，3 秒內自動攔截無效電郵，杜絕流程掛起 30 天。Uses Configure run after on Get user profile (V2) failures/timeouts to auto-reject invalid emails in 3 seconds, preventing 30-day hangs.

3. 獨立三級欄位冪等性Tiered Field Isolation

資料庫拆解 ManagerAction、HRAction 與 CODAction 獨立欄位與簽核時間戳，確保多級意見互不覆寫。Separates ManagerAction, HRAction, and CODAction columns and timestamps so multi-tier audit trails never overwrite.

4. 雲端時區標準化HKT Timezone Normalization

透過 convertTimeZone 函數統一將雲端 UTC 轉為 UTC+8 香港標準時間，消除深夜出勤紀錄之 8 小時時差爭議。Normalizes cloud UTC to UTC+8 Hong Kong Time via convertTimeZone expressions, eliminating 8-hour shift audit discrepancies.
