📌 專案摘要 (Executive Summary)

This repository is an Enterprise Demo showcasing how to implement Governance-as-Code using M365 and Zero-Trust architecture.

本專案將傳統紙本「非營運時段上班記錄表 (Demo-Form)」全面數位化，以 Microsoft 365 原生生態 為基礎架構，在零額外 Power Platform 授權費用下，整合目錄防呆、動態多級審批、HKT 標準時間戳與全鏈路閉環通報，全面對齊 ISO 國際管理體系。

🏛️ 流程生命週期與治理閉環 (Workflow Lifecycle)

1. 填報立案
Forms 身分鎖定
登入驗證、建立流水單號並回寫 SharePoint 核心清單。
2. 目錄防呆
主管電郵驗證
向 Entra ID 核實主管身分；異常則自動攔截退回，防止流程死結。
3. 部門審批
第 1 棒主管審核
核實申報必要性；駁回即時通知，通過則推進至 HR 審查。
4. 人資合規
第 2 棒 HR 審核
核對勞工條例工時規範與事由合理性，呈交高階營運主管批核。
5. 決策閉環
第 3 棒 COD 批核
高層核准歸檔，自動派發結案公函並抄送 HR 留存，完成審計鏈。

📋 業務治理矩陣 (Governance Matrix)

階段 責任角色 承載技術 處置動作與審計紀錄
填報立案 申報員工 Microsoft Forms + SharePoint 限定內部帳號登入，生成唯一單號（OT-YYYYMMDD-ID），初始狀態為 主管審批中。
目錄防呆 自動引擎 Office 365 Users (`Get user profile`) 自動驗證主管電郵是否合法存在；無效則經由 Scope 攔截自動標記 已駁回 並發信。
收件確認 自動引擎 Outlook (Office 365) 目錄驗證通過後發信告知申報單號與審批主管姓名，落實勞資溝通透明度。
第 1 棒主管審批 部門主管 Outlook / Teams Approvals 動態派發至部門主管；駁回即通知結案，通過則將狀態推進至 HR審核中。
第 2 棒 HR 審核 人力資源部 Outlook / Teams Approvals 人資部門進行法定合規覆核；通過則將狀態推進至 COD審批中。
第 3 棒 COD 批核 高階主管 Outlook / Teams Approvals 營運最高層最終核准，系統回寫狀態為 已批准歸檔 並蓋印時間戳。
閉環通報 系統閉環 Outlook (Office 365) 發送結案公函給申報員工，並副本 (Cc) 備查信箱，完成閉環。

⚖️ 法律法規與 ISO 標準合規 (Regulatory & ISO Standards)

合規適用性聲明 (Statutory Notice)：本系統展示架構依循常見個人隱私條例保護原則（如資料最小化、保存期限與加密防護）。

ISO/IEC 27001 & 27701 (資安與隱私)

清單執行 RBAC 最小權限原則，外部完全隔離；審核歷史記錄具備不可篡改性與標準時區審計軌跡。

ISO 9001:2015 (品質管治)

落實條款 7.5 成文資訊管理，取代易丟失、不可追溯之傳統紙本，提升跨部門審批一致性與效率。

ISO 45001:2018 (職安健體系)

落實條款 6.1 & 8.1 危害辨識，精準監控非營運時段之單獨作業安全與超時工作健康風險。

豁免範疇 (Exemption Notice)

本系統為確定性規則引擎，無機器學習模型，宣告排除 EU AI Act / ISO 42001；僅展示企業內部架構，宣告排除境外跨境傳輸法規。

⚙️ 技術亮點 (Technical Implementation)

1. 零額外授權架構 (Zero-License)

全流程僅調用 M365 商業版/企業版標準連接器，無需採購任何 Power Platform Premium 授權。

2. 目錄級異常攔截 (Exception Handling)

利用 Scope 錯誤捕獲配置（Run after has failed），主動攔截錯誤主管電郵，保障流程永不掛起。

3. 動態多階狀態機 (State Machine)

以明確狀態驅動審批生命週期，完整記錄每一階之 Action、Comments 與時間戳記。

4. 時區正規化 (Timezone Normalization)

全系統強制透過 Convert time zone 轉為本地標準時間，杜絕雲端預設 UTC 引發之審計爭議。
